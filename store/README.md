Merchant Center ID: `5624520187`

## What this build does

- Adds a responsive storefront for the existing commercial lanes.
- Adds Google's current Merchant Widget to the storefront.
- Adds a Google Customer Reviews survey opt-in integration bound to Merchant Center `5624520187`.
- Validates required order fields before loading the survey opt-in.

## Run locally

```bash
cd store
npm install
OPENAI_API_KEY=... npm start
```

Then open `http://localhost:3000`.

The store remains usable without an OpenAI key; only `/api/advisor` is disabled.

## Google Customer Reviews production gate

Google requires the survey opt-in on the actual HTTPS order-confirmation page. The production checkout must server-render a real `window.ORDER_RECEIPT` object containing:

- `order_id`
- `email`
- `delivery_country` as ISO 3166-1 alpha-2
- `estimated_delivery_date` as `YYYY-MM-DD`
- optional product GTINs

Use `public/order-confirmation.example.html` as the integration contract. Do not put customer email or order details in URL query parameters.
